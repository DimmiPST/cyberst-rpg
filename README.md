# cyberst-rpg
CYBERST é um RPG de terminal em Python com estética Cyberpunk/Sci-Fi retro. Explore uma narrativa imersiva com glitches, combate e mistérios, enquanto gerencia seu inventário e atributos. Projeto desenvolvido para dominar a linguagem Python, manipulação de arquivos JSON e estruturas de dados de forma prática e interativa.
