# cyberst-rpg
🛸 CYBERST — RPG Terminal Engine
"Bem-vindo ao Projeto Cyberst... Talvez algo tenha dado errado no servidor."

📖 Sobre o Projeto
O CYBERST é um jogo de RPG jogável diretamente no terminal, desenvolvido em Python. O projeto combina uma narrativa envolvente no estilo cyberpunk/scifi retro com mecânicas clássicas de RPG como criação de personagem, gerenciamento de inventário e exploração.

Este projeto foi construído para explorar e dominar conceitos essenciais de desenvolvimento em Python, incluindo:

Estrutura de dados avançada (dicionários e listas de itens).

Manipulação e persistência de dados (arquivos JSON/TXT).

Organização modular de código e boas práticas com Git.

💻 Recursos e Funcionalidades
🎭 Prólogo Imersivo: Animações de texto em tempo real com efeitos de glitch e arte ASCII.

👤 Ficha do Jogador: Criação e armazenamento dinâmico de status do personagem.

🎒 Sistema de Inventário: Manipulação de itens, armas e descrições detalhadas com formatação limpa no terminal.

🎨 Interface Colorida: Utilização de códigos ANSI para estilizar diálogos e alertas com cores chamativas.

💾 Persistência de Dados: Carregamento e salvamento do progresso via arquivos externos.
